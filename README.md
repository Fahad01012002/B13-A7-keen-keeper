1.  Project Name:
    KeenKeeper

2.  Project Description:
    KeenKeeper is a website that helps users track their interactions with friends. It allows you to see when you last contacted someone and keeps records of how much time you’ve spent communicating through audio calls, video calls, or text messages. You can also add new friends easily. This app is especially useful for people who are busy or tend to forget to stay in touch, as it helps them keep track of their relationships.

3.  Technologies Used:
    To build this website, I used the popular framework Next.js. I also integrated libraries such as Toastify, Pie Chart, and Lucide Icons to enhance functionality and user experience.

4.  Key Features:

    1.Interaction Tracking: Tracks call, video call, and text message details.
    2.Detailed Friend Insights: Displays comprehensive information about each friend.
    3.Visual Analytics: Shows total counts of calls, video calls, and texts using charts, making it easy to understand interaction patterns.
